KNIFE CLIENT (Fabric, Minecraft 1.21.4) - client-side cosmetics
Modules: Glow Skin, Headless, Korblox Leg, Knives instead of fists (4 knives).
Press RIGHT SHIFT in-game to open the menu. Only YOU see these effects.

EASIEST WAY TO BUILD (no Java needed): use GitHub
 1. Make a free account at github.com and click New repository (name: knifeclient, Public).
 2. Click "uploading an existing file", drag in EVERYTHING inside this folder
    (including the .github folder), then click Commit changes.
 3. Open the Actions tab. If it asks, click the green button to enable workflows.
    Click the "build" run (or Run workflow). Wait ~5 minutes for the green check.
 4. Click the finished run, scroll to Artifacts, download knifeclient-mod.
    Unzip it: the .jar inside is your mod.

INSTALL
 1. Install Fabric Loader for Minecraft 1.21.4 (fabricmc.net/use).
 2. Download Fabric API for 1.21.4 from modrinth.com/mod/fabric-api.
 3. Put knifeclient-1.0.0.jar AND the Fabric API jar into .minecraft/mods
 4. Start the Fabric 1.21.4 profile, join a world, press Right Shift.

Replace the knife art: assets/knifeclient/textures/item/*.png
